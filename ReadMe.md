I builds practical systems at the intersection of embedded software, cross-platform applications, and networked infrastructure. Working with C++, C, Python, JavaScript, and Qt/QML, the focus is on systems that operate outside a demo environment — offline-capable, power-efficient, and deployable at scale.

## What I Build

- **Cross-platform applications:** Qt 6 / QML applications for Windows and Android with SQLite caching, hash-based synchronization, offline-first architecture, and local-server deployment paths.
- **Embedded and IoT systems:** ATmega328P, AVR-GCC, moisture/motion sensors, SPI/UART, SX1278 LoRa telemetry, low-power operation, PCB design, and sensor networks.
- **Connected infrastructure:** Raspberry Pi edge systems with centralized publishing, remote device management, environmental sensing, movement and ambient-light sensing, multi-display coordination, and fault-response workflows.
- **Automation and browser tools:** Manifest V3 Chrome extensions using JavaScript, content scripts, service workers, esbuild, and Chrome Extension APIs with MutationObserver-based monitoring.

## Featured Work

- **WLDU App:** Qt 6 / QML university platform for Windows and Android with SQLite caching, hash-based synchronization, managed updates, content upload utility, self-update mechanism, and offline-first architecture.

- **Smart Digital Signage System:** Raspberry Pi network with 130+ displays across 20 buildings. Uses Python, C++, JavaScript, Flask/FastAPI, movement sensing, ambient-light sensing, and automatic brightness adjustment for energy-aware operation.

- **Subterranean Landslide and Flood Early-Warning Network (SLF-EWN):** C-based embedded system using ATmega328P sensor nodes, 433 MHz LoRa (SX1278) telemetry at 100–200m range, W25Q64 SPI flash storage, CRC-8 validation, 12-byte sensor frames, watchdog-based hibernation, FET-gated power, and Qt/QML dashboard. Targets 3–7 year battery life.

- **Browser Automation Extension:** Manifest V3 Chrome extension with JavaScript, content scripts, service workers, esbuild, and Chrome Extension APIs. Implements dynamic frame-based interfaces with MutationObserver debouncing and tab-specific state isolation.

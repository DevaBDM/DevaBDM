I am Dawit Berhan, a Software and Systems Engineer building practical technology across cross-platform applications, embedded systems, networking, automation, and hardware-software integration.

## What I Build

- Cross-platform applications: Qt 6 / QML applications for Windows and Android, including offline-capable data handling and local-server deployment paths.
- Embedded and IoT systems: ATmega328P, AVR-GCC, sensors, SPI/UART, LoRa telemetry, low-power operation, PCB design, and practical monitoring devices.
- Connected infrastructure: Raspberry Pi edge systems, centralized publishing, remote device management, environmental sensing, and networked displays.
- Automation and browser tools: Manifest V3 Chrome extensions, content scripts, service workers, MutationObserver-based monitoring, and event-driven browser workflows.
- Engineering experiments: C++, databases, networking, electronics, simulations, and tools that reduce repetitive work or make technical ideas more useful.

## Engineering Principles

I care about systems that are useful outside a demo. That means thinking about offline operation, maintainability, power use, physical constraints, testing, clear documentation, and honest status boundaries. I distinguish between a design, a simulation, a working prototype, and a deployed system.
